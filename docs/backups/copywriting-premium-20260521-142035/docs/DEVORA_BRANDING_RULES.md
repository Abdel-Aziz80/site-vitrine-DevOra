# DEVORA Branding Rules

## Marque

La marque principale s'ecrit toujours `DEVORA`.

Ne pas varier la casse dans les contenus publics.

## Ton

Le site doit rester concret :

- pas de promesse magique ;
- pas de faux marketing ;
- pas de depot public des produits internes ;
- des fonctions, des captures reelles et des usages clairs.

## Positionnement

DEVORA n'est pas un simple portfolio freelance. Le site doit porter une image
produit autour de l'IA locale, l'automatisation, les dashboards, la securite
defensive et les systemes metier.

## Visuels

Les produits internes doivent etre montres uniquement via :

- captures reelles ;
- interfaces locales ;
- dashboards existants ;
- descriptions fonctionnelles.

Les faux mockups ne doivent pas remplacer une capture produit validee.
