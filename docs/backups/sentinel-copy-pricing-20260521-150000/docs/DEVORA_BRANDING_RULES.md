# DEVORA Branding Rules

## Marque

La marque principale s'ecrit toujours `DEVORA`.

Ne pas varier la casse dans les contenus publics.

## Ton

Le site doit rester concret :

- pas de promesse magique ;
- pas de faux marketing ;
- pas de depot public des produits internes ;
- des fonctions, des vues controlees et des usages clairs ;
- un langage accessible aux non-techniciens.

## Positionnement

DEVORA n'est pas un simple portfolio freelance. Le site doit porter une image produit autour de l'IA locale, l'automatisation utile, les tableaux de pilotage metier, la securite defensive et les systemes internes.

## Visuels

Les produits internes doivent etre montres uniquement via :

- captures reelles validees ;
- interfaces locales controlees ;
- vues publiques limitees ;
- apercus animes fictifs quand une capture complete serait trop sensible ;
- descriptions fonctionnelles.

Les apercus fictifs ne doivent jamais reveler d'architecture, de secret, de logique metier profonde ou de vrai fonctionnement interne. Ils servent a proteger les produits tout en montrant que DEVORA possede une vraie matiere produit.
