# DEVORA Sentinel

## Definition publique

DEVORA Sentinel est un outil local de surveillance et d'assistance defensive. Il aide a visualiser certaines activites systeme, suivre des signaux techniques, centraliser des incidents et rendre les alertes plus comprehensibles depuis une interface locale.

Le message public prioritaire :

> DEVORA Sentinel aide a surveiller, visualiser et mieux comprendre certaines activites techniques, avec une logique defensive, lisible et controlee.

## Positionnement

Sentinel doit etre compris comme :

- un outil local premium ;
- un assistant de visibilite systeme ;
- un espace de suivi des incidents ;
- une aide defensive avec validation humaine ;
- un produit transparent et controle.
- un produit desktop en Early Access, avec une version telephone portable en cours de developpement.

La page DEVORA Sentinel doit rester visuellement dans le meme univers que les autres pages DEVORA : bleu profond, cyan, violet, surfaces premium, glow subtil, cartes sobres et aucun branding separe.

Sentinel ne doit pas etre presente comme :

- un spyware ;
- une IA magique ;
- un cloud invasif ;
- un antivirus miracle ;
- un systeme qui agit sans validation.

## Confidentialite

Principes publics a repeter clairement :

- donnees locales par defaut ;
- aucune collecte cachee ;
- aucune revente de donnees ;
- aucune action automatique agressive ;
- validation humaine sur les actions sensibles ;
- fonctionnement offline partiel ;
- veilles externes uniquement sur sources autorisees.

Phrase a rendre visible quand le contexte s'y prete :

> Vos donnees restent sur votre machine par defaut. Sentinel n'a pas vocation a envoyer vos informations dans un cloud invasif.

## Ce que Sentinel surveille

Formulation publique recommandee :

Sentinel aide a suivre des signaux techniques, evenements systeme, alertes, incidents, changements inhabituels, elements a verifier et historiques utiles. Le perimetre exact depend du profil et de la configuration validee.

Ne pas publier :

- regles internes detaillees ;
- architecture complete ;
- mecanismes de detection avances ;
- sources privees ;
- logique AlexCore ou runtime interne.

## Publics cibles

- createurs ;
