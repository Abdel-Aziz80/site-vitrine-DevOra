## Regle GitHub

Les noms produits peuvent apparaitre dans le site, mais les dossiers internes, sources et depots prives ne doivent pas etre publies depuis la vitrine.

## SEO

Les titres SEO doivent privilegier :

- le nom produit ;
- la fonction concrete ;
- le public cible ;
- la nature defensive ou locale quand c'est pertinent.

Dans les contenus publics, eviter les libelles trop techniques ou trop internes si une formulation simple suffit. Exemple : preferer "tableau de pilotage" a "dashboard", "espace de suivi" a "cockpit", et "bouton de contact" a "CTA".
